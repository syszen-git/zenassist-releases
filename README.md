# ZenAssist : versions publiées

Ce dépôt ne contient **que les installeurs** de ZenAssist, l'assistant informatique des postes gérés par SysZen. Ils sont publiés ici pour que l'application se mette à jour toute seule.

- Les installeurs sont **signés par SysZen** : l'application refuse toute mise à jour dont la signature ne correspond pas.
- Ils ne contiennent **aucune configuration ni aucun secret** : la configuration de chaque client est déployée à part.
- Le code source est privé.
